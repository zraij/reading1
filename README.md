# قراءتي الجديدة — الأول الابتدائي

كتاب ناطق تفاعلي لكتاب «قراءتي الجديدة» للصف الأول الابتدائي، مصمَّم للشاشات التفاعلية (أندرويد): قصص بشخصيات متحركة، وتهجئة، وتتبّع الحروف بالإصبع، وأنشطة كتاب النشاط كألعاب، ودليل المعلم داخل كل درس.

- **الموقع:** https://zraij.github.io/reading1/ (يحتاج تسجيل دخول)
- **إدارة الحسابات:** https://zraij.github.io/reading1/admin.html
- **لوحة إدارة موحّدة:** نفس `admin.html` موجود بكل الكتب ويدير كل الكتب من مكان واحد (أزرار للتبديل بين الكتب). أي تعديل عليه لازم ينسخ لكل المستودعات.
- **الاشتراكات:** كل حساب (عدا المدير) له تاريخ انتهاء `e` بـ `users.json` (`pm` = عدد الأشهر، `tr` = أيام التجربة). الحسابات القديمة بدون تاريخ تنتهي `2026-12-01` (من 1 تشرين الثاني لمدة شهر). عند الانتهاء تظهر شاشة التجديد برقم 07746451098.
- **تنبيه للمطوّر:** كود الاشتراك (`subFetch` / `subExpired` / `subBadge`) مضاف بالجزء غير المشفّر من `index.html`؛ بعد أي إعادة بناء تأكد أنه موجود.
- **رابط التثبيت (للأساتذة والشاشات):** https://zraij.github.io/reading1/install.html

محتوى البرنامج مشفّر ولا يُفتح إلا بحساب صحيح، مع قفل الجهاز (نفس خدمة الكيمياء والفيزياء) وحقوق المصمم.

## الأصوات
- `tts/manifest.json` فيه كل الجمل المنطوقة. ملفات MP3 تتولد في مجلد `audio/`.
- التوليد التلقائي: تبويب **Actions** ← «توليد الأصوات» ← Run workflow (يشتغل تلقائياً عند تغيّر القائمة).
- أو على الحاسبة: `pip install edge-tts` ثم `python tts/make_audio.py`.
- إذا ملف الصوت غير موجود يستعمل البرنامج صوت المتصفح احتياطاً، والمعلم يكدر يسجل صوته لأي كلمة (وضع المعلم ← ضغط مطوّل).
