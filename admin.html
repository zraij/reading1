إضافة حساب —

بعد الإضافة اضغط «حفظ التغييرات» في الأسفل حتى يتفعّل الحساب.

ربط GitHub للحفظ

✓ مربوط — توكن واحد لكل الكتب، محفوظ على هذا الجهاز ومحفوظ مشفّر ويّا حسابك، فما تحتاج تجيبه مرة ثانية.

مرة وحدة بس: التوكن ينحفظ على هذا الجهاز، وينحفظ مشفّر ويّا حسابك حتى يرجع تلقائياً إذا دخلت من جهاز ثاني.

  1. افتح صفحة إنشاء التوكن.
  2. اكتب أي اسم، وبـ Expiration اختر No expiration (أو أطول مدة موجودة).
  3. Repository access ← All repositories (حتى يشتغل لكل الكتب).
  4. Permissions ← Contents ← Read and write.
  5. Generate token، انسخه والصقه هنا.
